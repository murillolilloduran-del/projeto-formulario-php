# Projeto PHP — Formulário e Processamento

##  Sobre o projeto

Este projeto foi desenvolvido como uma atividade prática do curso de **Análise e Desenvolvimento de Sistefamas (ADS)**.

Os arquivos utilizados inicialmente foram fornecidos pelo professor como base para a atividade. A partir deles, foram realizadas modificações com o objetivo de praticar conceitos de **HTML, CSS e PHP**, além da integração entre uma página web e o processamento de dados.

##  Tecnologias utilizadas

* HTML5
* CSS3
* PHP

##  Estrutura do projeto

```text
projeto/
├── index.html
├── style.css
└── receber.php
```

### `index.html`

Página principal do projeto, contendo a estrutura do formulário e os elementos da interface.

### `style.css`

Arquivo responsável pela estilização e organização visual da página.

### `receber.php`

Arquivo responsável pelo recebimento e processamento dos dados enviados pelo formulário.

##  Objetivo

A atividade teve como objetivo desenvolver a prática com:

* Estruturação de páginas HTML;
* Estilização com CSS;
* Criação e utilização de formulários;
* Envio de dados entre páginas;
* Processamento de informações utilizando PHP;
* Modificação e adaptação de códigos previamente fornecidos.

##  Contexto

Projeto desenvolvido para fins **educacionais**, como parte dos estudos em Desenvolvimento de Sistemas.

Os códigos iniciais foram disponibilizados pelo professor para que fossem analisados, modificados e adaptados durante a atividade.
